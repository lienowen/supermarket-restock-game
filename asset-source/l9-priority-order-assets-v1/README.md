# L9 Priority Order source assets

Production-ready transparent PNG cutouts prepared for the L9 express-picking scene.

- `worker-priority-picker.png`: employee holding the picking basket; the basket is intentionally part of the character sprite.
- `product-cereal-box.png`: cereal order item.
- `product-milk-jug.png`: milk order item.
- `product-apple.png`: apple order item.

L10 reuses the L9 picker for its Priority Pick stage. Its Safety Cleanup and Final Restock stages already have dedicated hazard, warning-sign, cooler, worker and case assets, so no duplicate L10 cutouts are included here.
