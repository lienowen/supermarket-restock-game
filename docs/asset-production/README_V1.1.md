# 超市项目全局素材包 V1.1

## 目录原则

本包已经按真实项目目录整理，P0/P1/P2不再作为文件夹。

- `public/assets/game/production-v1/`
  - 游戏运行时直接加载的WebP资源。
- `asset-source/production-v1/`
  - 美术源PNG，用于后续修图、重导出。
- `docs/asset-production/`
  - 接入清单、路径映射、预览图。

## 核心规则

1. 关卡不能拥有自己的重复素材目录。
2. 同一冷柜、污渍、称重台、UI状态通过全局assetKey复用。
3. 优先级仅用于排期，不参与目录结构。
4. 冷柜库存由空柜、商品对象、玻璃反光层组成。
5. 打烊效果使用全局灯光遮罩，不制作新的整张场景。
