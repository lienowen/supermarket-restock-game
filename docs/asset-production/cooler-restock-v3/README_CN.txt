冷柜补货核心素材包 V3

文件说明
--------
market_bg_hd.png
  高清超市场景背景。

cooler_empty_back_hd.png
  高清空冷柜，用于缺货状态。

cooler_front_glass_hd.png
  高清双门冷柜前景参考，用于门框、把手和玻璃遮挡。

推荐用途
--------
1. market_bg_hd.png 作为第一关世界背景。
2. cooler_empty_back_hd.png 用作补货近景的空柜底层。
3. 动态生成单瓶商品，按 2 列 × 3 层摆放。
4. cooler_front_glass_hd.png 放在商品上方形成柜内遮挡。

注意
----
三张图片目前尺寸和构图并非像素级同画布分层。
接入时应采用“世界场景 → 冷柜近景补货”的切换方式，
不要直接把三张整图硬叠在同一世界坐标中。
