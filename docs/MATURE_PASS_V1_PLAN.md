# Mature Pass V1 Plan

## Goal
Upgrade the game from playable prototype to a consistent commercial-quality supermarket simulation.

## Phase 1: Level 5 Golden Level

### P0 Visual Foundation
- Fix character transparency
- Establish character/object scale rules
- Fix background clarity and camera presentation
- Standardize shadows, ground contact, and perspective

### P0 Gameplay Foundation
- Keep find-items gameplay as the core loop
- Add search -> pickup -> carry -> place -> feedback flow
- Add similar-item distraction and decision making

### P1 Polish
- Pickup animations
- Placement feedback
- NPC movement
- UI simplification
- Audio feedback

## Phase 2
Apply Level 5 standards to Levels 1-7 and freeze.

Freeze criteria:
- Visual consistency
- Fun gameplay loop
- Clear feedback
- Technical stability
