# 补货从空货位到满货位的强制验收规则

## 问题说明

旧实现会在关卡开始时预先创建整层商品，再通过极低透明度隐藏；上架成功后把整层透明度改为 1。视觉结果更像移除遮挡或点亮图片，不是真实地把商品放上货架。

该实现已经废弃，禁止恢复。

## 强制规则

- 每个冷柜货位容量为 3 件商品。
- 空货位必须拥有 0 个商品对象，不能预生成商品后设为透明。
- 每次正确操作只增加 1 件商品。
- 货位必须真实经历 `0/3 → 1/3 → 2/3 → 3/3`。
- `1/3` 和 `2/3` 时不能增加已完成货位数，也不能切换下一货位。
- 第 3 件商品落架后，该货位才判定完成并激活下一货位。
- 商品必须从打开的箱子或补货车位置移动到目标货架，落在货架基线上并保留。
- 6 个货位共需完成 18 次真实上架。
- Level 1、Level 2、Level 6、Level 10 都必须执行相同的真实库存规则。

## 自动验收

自动验收同时读取：

1. `RestockRushController.rowItemCounts` 中的库存状态；
2. Phaser 货架容器中的实际商品对象数量；
3. `RestockSceneController.stockedRows` 中的完成货位数。

三者必须满足：

- `0/3`：商品对象 0，完成货位数不增加；
- `1/3`：商品对象 1，完成货位数不增加；
- `2/3`：商品对象 2，完成货位数不增加；
- `3/3`：商品对象 3，完成货位数增加 1；
- 六层完成：商品总数 18，每层均为 3。

## 截图验收

Level 1 必须生成并人工检查以下截图：

- `restock-shelf-0-of-3.png`
- `restock-shelf-1-of-3.png`
- `restock-shelf-2-of-3.png`
- `restock-shelf-3-of-3.png`

Level 2 专项验收还必须确认：

- 记忆预览结束前货位不可操作；
- 正式阶段不显示下一货位答案；
- 错误点击不改变正确目标；
- 同一个正确目标在 `1/3`、`2/3` 时保持不变；
- 第 3 件才进入下一目标；
- 最终完成 18 件商品。
